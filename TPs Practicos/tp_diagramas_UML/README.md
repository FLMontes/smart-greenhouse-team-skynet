El objetivo de este trabajo es modelar la logica de negocio del ingreso de socios al complejo con diagramas UML.

- Diagrama de Actividad

## Herramienta utilizada
Miro

## Escenario principal
El socio apoya la pulsera RFID, el sistema valida que tenga la cuota al día, registra el horario y DNI, y habilita el molinete.

## Escenario alternativo offline
Si no hay conexión a internet, el sistema valida contra una cache local de socios habilitados y permite el ingreso a quienes ya pagaron.
